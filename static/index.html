Security & Input Validation Controls

Operational guardrails enforcing data integrity and privacy

1. Safe File Loading

Exceptions handled gracefully. Users receive sanitized messages without exposing raw system tracebacks or stack dumps.

2. Schema Validation

Ensures required columns exist (timestamp, module, event_type, status, duration_ms).

3. Type Validation

Coerces numeric fields and parses ISO timestamps. Rejects corrupted rows with invalid date formats or malformed types.

4. Duration Boundary Check

Enforces duration_ms ≥ 0. Negative durations (physically impossible) are rejected as corrupted or tampered data.

5. Duplicate Row Check

Detects exact duplicate entries and triggers a warning banner without halting execution or exposing sensitive logs.

6. Privacy-First Audit Logs

Logs only metadata (timestamps and filter criteria). No passwords, API keys, IP addresses, or personal identifiers are stored.
